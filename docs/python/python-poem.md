# Поэма о питоне

Питон вздохнул из-под куста:  
«Как жизнь без ног-то непроста!  
Зато не надо по утрам  
Искать носки по всем углам».  

Забрался тихо на сучок,  
Свернулся плотно, как клубок.  
Лежит, не падает ничуть:  
«Вот тут и можно отдохнуть».  

А ночью снился сон питону:  
Он шёл в ботинках по газону.  
Проснулся, глянул на росу:  
«Вот это лишнее в лесу!»
